Entry for make.fun bounty `u-ronigrv-the-one-line-laugh-7ccca46f`
("The One-Line Laugh") by @expylar. See the bounty page at
https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f.

One funny line, one sentence, 183 characters:

> I bought a robot vacuum to save time, so now I spend my evenings rescuing it from cables, untangling it from curtains, and apologising to a machine that bumps into walls for a living.

`main.py` writes that line to `/output/entry.txt`, deterministically,
one run after another, byte for byte.
